Built for real workflows

From raw data
to cited answers.

A full-stack foundation for building retrieval-augmented applications, with the security and operational pieces already connected.

01 / INGEST

Bring your knowledge in

Extract text from PDFs or sync ERP/CRM records through a shared chunking and embedding pipeline.

02 / RETRIEVE

Find relevant sources

Use Qdrant vector search with tenant and document filters to keep retrieval scoped to authorized data.

03 / ANSWER

Ground every response

Generate answers from retrieved content, with inline citations and a clear response when no source matches.

04 / SECURE

Control access

Combine sessions, API keys, RBAC, OAuth2 scopes, rate limits, and per-client AI usage quotas.

05 / OPERATE

See what happened

Track document status and errors, persist chat threads, and run with Docker Compose in development or production.

06 / EXTEND

Make it your own

Layered Rust backend, swappable repositories, OpenAPI docs, and a React admin UI ready to customize.

A simple, explicit pipeline

Your sources in.
Evidence out.

The same ingestion path handles files and structured external data. Answers are independently grounded in retrieved sources.

01

PDF / ERP

Upload a document or sync business records.

02

Extract & chunk

Optionally redact PII, then split text into overlapping chunks.

03

Embed & index

Create embeddings and store vectors and payloads in Qdrant.

04

Retrieve

Embed the question and find authorized, relevant chunks.

05

Answer with sources

Generate a grounded response with citations.

Designed for isolation. Authorization and OAuth scopes guard the API; owner and document filters constrain retrieval. Chat history is saved for the user but is not fed back into the answer prompt.
